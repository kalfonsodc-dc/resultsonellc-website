Accessibility Statement for Results One

This is an accessibility statement from Results One LLC.

Measures to support accessibility

Results One LLC. takes the following measures to ensure accessibility of Results One:

  • Integrate accessibility into our procurement practices.
  • Appoint an accessibility officer and/or ombudsperson.
  • Employ formal accessibility quality assurance methods.

Conformance status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA. Results One is fully conformant with WCAG 2.1 level AA. Fully conformant means that the content fully conforms to the accessibility standard without any exceptions.

Compatibility with browsers and assistive technology

Results One is designed to be compatible with the following assistive technologies:

  • Chrome with JAWS on Windows
  • Firefox with NVDA on Windows
  • Safari with VoiceOver on Mac

Results One is not compatible with:

  • Mobile operating systems older than 5 years

Technical specifications

Accessibility of Results One relies on the following technologies to work with the particular combination of web browser and any assistive technologies or plugins installed on your computer:

  • JavaScript

These technologies are relied upon for conformance with the accessibility standards used.

Limitations and alternatives

Despite our best efforts to ensure accessibility of Results One LLC, there may be some limitations. Below is a description of known limitations, and potential solutions. Please contact us if you observe an issue not listed below.

Known limitations for Results One:

1. There is a carousel of images with text and occasional buttons, configured using an Elementor module or addon, which cannot be modified to meet accessibility compliance standards. The issue arises from specific boxes (divs) designated as images using the HTML attribute role=’img’, while these boxes merely serve as containers with images set as backgrounds using CSS. This causes a compliance issue that can be classified under various items of both WCAG 2.1 and Section 508 of the Rehabilitation Act. Various solutions were attempted, including using basic, advanced, and customized Elementor tools, adding specific IDs to each slide, incorporating ARIA tags, attempting to change the role using JavaScript, and applying custom code. Despite these efforts, the configuration of the addon remained unchanged. The team is currently looking for a substitute for this module.
